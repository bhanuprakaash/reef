# Reef

A personal Mac app where every feature keeps its own memory, and a team of AI agents works on it together in one window.

Spec: [docs/product.md](docs/product.md)

## Install

Needs an Apple Silicon Mac, and `claude` and/or `codex` on your PATH.

```sh
curl -fsSL https://raw.githubusercontent.com/bhanuprakaash/reef/main/scripts/install.sh | sh
```

The same command updates Reef: it quits the app, replaces it and opens it again.
