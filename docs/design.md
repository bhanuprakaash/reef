# Reef: design

The UI design lives in a Claude Design canvas: https://claude.ai/artifact/CGK94EmGe6jYLM9SgE7CTK

Read the yellow "design language" note on the canvas first; each board has a note with its intent. Edit the canvas, not a copy.

- Look: modelled on the Grok Bot desktop app (sidebar of chat-style rows, grey bubbles, user messages in light pills, pill composer). Reef keeps its own content: projects, Work items, Spaces, Teams, Teammates, limits, brief, memory, inbox.
- Messages: a Bot bubble is a 4.5% lift of the text colour on the page with a 1px edge; inline code is sand `#E6B98A` (light `#A24A1C`) text with no box; code blocks keep a soft box; the Reply button under a bubble is always visible.
- Type: Geist (self-hosted), regular weight.
- Colours: sidebar `#1A1A1A`, main `#171717` (light `#F8F8F9`), cards `#2A2A2A`, bubbles `#2E2E2E`, text `#ECECEC`, muted `#9B9B9B`.
- Bots are reef creatures with the same two eye ticks: lead jellyfish `#F26B2E` (also the logo), architect whale `#8B5CF6`, developer penguin `#3FBFA0`, tester shark `#3B82F6`. Added roles are pebbles.

The canvas is updated from screenshots of the built app (`verify-reef ui`); it has no feature, channel, gate, task or promote board.
