# Reef: design

The UI design lives in a Claude Design canvas: https://claude.ai/artifact/CGK94EmGe6jYLM9SgE7CTK

Read the yellow "design language" note on the canvas first; each board has a note with its intent. Edit the canvas, not a copy.

- Look: modelled on the Grok Bot desktop app (sidebar of chat-style rows, grey bubbles, user messages in light pills, pill composer). Reef keeps its own content: projects, features, channels, teams, gates, limits, brief, decisions, inbox.
- Type: macOS system font, regular weight.
- Colours: sidebar `#1A1A1A`, main `#212121`, cards `#2A2A2A`, bubbles `#2E2E2E`, text `#ECECEC`, muted `#9B9B9B`.
- Bots are reef creatures with the same two eye ticks: lead jellyfish `#F26B2E` (also the logo), architect whale `#8B5CF6`, developer penguin `#3FBFA0`, tester shark `#3B82F6`. Added roles are pebbles.
- Boards: channel, bots, logo, shared sidebar, teams, feature, needs-you inbox, and four mobile screens.
