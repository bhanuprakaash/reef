Search

Full-text search

An FTS5 index over body and why, kept in step by triggers, with a scope and status filter.

Issue #25302f1fbmemory-servicebased on docs/restructure-proposal

What it does

Search(query, filter) returns ids ranked by BM25, best first. The porter tokenizer stems words, so retries finds retry. The filter names the allowed scopes. Only accepted items come back, plus retired ones marked retired when the filter asks. Candidates never come back.

Why

Decision R19: word-exact search is half of hybrid recall. Scopes are the shelves an asker can see (R1, R16), so an empty scope list returns nothing, never everything.

How a request flows

Decisions made while building

Score

Score = -bm25(), so higher is better, the same as cosine later.

Empty scope id

A scope with an empty id matches only items with an empty id. It is not a wildcard.
