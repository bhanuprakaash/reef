Closes the hole review found in #41: a live note now ranks above the note it replaced in every case.

What it does

rankBelowReplacers demotes an item whenever its replacer is in the results, whether the replacer matched the query or was reached by a link. load returns an id-to-replacer map, so the exported Hit type no longer carries a hidden field.

Why

With v1 → v2 → v3 and two unrelated notes ranked between v2 and v3, link expansion overwrote v3's direct mark, and the #41 rule skipped it: retired v2 came first.
