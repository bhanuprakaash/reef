What it does

reef memory add writes an item as author user, so it is always accepted. recall searches every scope and prints status and via per hit. show <id> prints one item with its why, author, links and retirement. retire, pending and approve manage status. Bare reef memory, show with no id and set still handle the old project blob.

Why

The user is the one writer the CLI has (R1, R21). The blob commands stay until the context assembler replaces project memory in channel/context.go.

Decisions made while building

All scopes

The CLI's visible scopes are the distinct scopes in the memory table.

Scope format

kind:id, for example project:1 or work_item:12.

Review fix: flags per subcommand

Each subcommand has its own flag set, so a stray flag prints that subcommand's usage with exit 1. Only --project and --data may come before the word.
