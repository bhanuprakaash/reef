Search

Embeddings, optional

Items can carry a vector from OpenAI or Voyage. With no key, nothing calls the network and search stays word-based.

Issue #2697b297bmemory-servicebased on docs/restructure-proposal

What it does

NewEmbedder(EmbedConfig{Provider, Key}, client) gives an Embedder. With no key it gives the none embedder, which returns no vector. Remember embeds after the item is stored; an embed error never fails the write. Backfill fills every missing vector later. Nearest ranks items by cosine similarity in Go, over the same scope and status filter that Search uses.

Why

Decision R20: Reef stays free and local by default; one setting turns on better search. R19: vectors are a blob column and cosine runs in Go, so no SQLite extension is needed.

Decisions made while building

Unknown provider

NewEmbedder returns an error. A typo must not silently turn recall into words only.

Models

OpenAI text-embedding-3-small, Voyage voyage-3-lite.

Mixed lengths

Nearest skips stored vectors of another length, so a provider switch does not break it.
