Embeddings

Embedding cost off the hot paths

Writes and recall never wait for a rate limit, and the duplicate check skips word search when every note has a vector.

Issue #45d216a4d5438a42memory-servicebased on docs/restructure-proposal

What it does

postJSON returns a typed statusError and never waits. Only Backfill waits out one 429 per item (Retry-After clamped to 1 to 60 s before multiplying). Backfill skips rejected notes. lookalikes runs its word check only when the scope has a note without a vector.

Why

Review measured 7.6 s per write at 5,000 vectored notes, all spent in a word search whose result was then thrown away. A 429 on the recall query stalled recall for the whole Retry-After. A huge Retry-After overflowed to a negative wait.
